# ADR-001: Local-first архитектура

- Статус: принято
- Дата: 2026-08-07

## Контекст

Safe to Spend предназначен для ведения личного бюджета без обязательной регистрации и постоянного подключения к интернету. Финансовые данные чувствительны, а первая версия не требует совместной работы или синхронизации между устройствами.

Приложение должно быстро открывать бюджет, сохранять операции без сети и не зависеть от доступности внешнего сервера.

## Решение

Основной экземпляр финансовых данных хранится локально на устройстве пользователя в IndexedDB.

В MVP отсутствуют:

- backend для финансовых данных;
- регистрация и авторизация;
- обязательная облачная синхронизация;
- фоновая отправка сумм на сервер.

После первого открытия PWA должна позволять просматривать и изменять данные без подключения к интернету. Пользователь самостоятельно запускает экспорт и импорт резервной копии.

## Последствия

Положительные:

- приложение работает без сети;
- операции не зависят от задержек сервера;
- финансовые данные по умолчанию не покидают устройство;
- MVP не требует разработки и эксплуатации backend;
- Web, PWA и мобильные оболочки используют одну модель данных.

Отрицательные:

- очистка данных браузера или удаление приложения может уничтожить базу;
- данные автоматически не появляются на другом устройстве;
- потеря устройства без резервной копии означает потерю данных;
- экспорт, импорт и предупреждения о локальном хранении входят в обязательный объём продукта.

## Рассмотренные альтернативы

### Серверная база как основной источник

Отклонена для MVP: требует backend, авторизации, сетевого протокола, защиты аккаунтов и обработки конфликтов синхронизации.

### localStorage

Отклонена: не подходит для структурированных связанных коллекций, транзакций, индексов и эволюции схемы.

### Облачная синхронизация вместе с локальной базой

Отложена до Post-MVP. Она потребует отдельного ADR о конфликтах, идентичности пользователя и модели синхронизации.
